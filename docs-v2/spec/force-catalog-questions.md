# Force catalog questions

Open items for the v2 Force catalog (force-catalog.md). An ability or form goes here when a field has no lore source, or when a legacy name has no Legends source. Resolve each item before the catalog entry ships; until then, the name is not in the catalog and the AI cannot use it.

## Catalog candidates (Legends source exists, outside Docs/SWRPG lore/)

|---|---|---|

Legacy name: MindDomination (5 uses in the legacy lore database) | **Resolved 2026-11-20:** merged into Mind Control as an alias (Wookieepedia: mind control is also known as dominate mind).
