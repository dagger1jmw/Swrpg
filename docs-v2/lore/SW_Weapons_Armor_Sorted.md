# Weapons and Armour: sorted research list

Research worklist for SWRPG, not a lore file. Built 23 Nov 2026 by Claude with one automated pass over the Wookieepedia API. It replaces working through SW_Weapons_Armor_CategoryIndex.md link by link; that file stays as the full link reference.

**How it was sorted**
- Read 4,482 Legends weapon and armour articles: the Weapons and Armor category trees plus Personal energy shields, leaving out starship, vehicle and emplacement weapons, superweapon branches, lightsaber colours, crystals, Sithspawn, Yuuzhan Vong weapons, and stormtrooper and clone armour.
- 1,812 of them appear in an Old Republic–era work (OR-era).
- Each was put into one of three layers:
  - **Layer 1, type pages (265):** generic pages ("Blaster pistol/Legends", "Vibroblade/Legends"). These define the weapon classes. Pull a priority subset for the class table.
  - **Layer 2, named in-universe items (155):** OR-era articles that appear in a novel, comic or reference book, not just a game. Each is listed with the useful infobox fields the API returned. Pull and write these up as the named variants.
  - **Layer 3, game-only items (1,405):** OR-era articles that appear only in KOTOR, SWTOR or other games (generated names such as "N-61 Rancor-X disruptor", "V-3 pyro grenade"). No individual pulls. They become each class's name pool for loot and shops. The names are in SW_Weapons_Armor_CategoryIndex.md under their categories.
- Infobox values are shown only where the page had a real value. Some Layer 2 rows are tagged OR-era only because a cross-era reference book (*Jedi vs. Sith: The Essential Guide*) lists them. Those are marked **(other era)** and are kept as reference only.
