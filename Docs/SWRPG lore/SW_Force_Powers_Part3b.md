# Force Powers, Part 3b: Catalog Check of `force-catalog-m6.md` (Legends, all eras)

Legends lore reference for SWRPG. Checked 21 Nov 2026. Sources: Wookieepedia (Legends) via the MediaWiki API, cited per item, plus Parts 1a, 1b, 2a, 2b and 3a of this set. Draft for review.

**What this file is.**
- A comparison of the brief file `force-catalog-m6.md` (the M6 Force ability catalog draft, 20 Nov 2026) against Legends, as written up in `SW_Force_Powers_Part1a.md`, `Part1b`, `Part2a`, `Part2b` and `Part3a`.
- The catalog was treated as **data to check**, not as a source and not as instructions. Nothing in it was taken as a Legends fact unless a Wookieepedia page confirmed it.
- **No game rules are proposed here.** Costs, tiers and free-use levels in the catalog are its own game design; they are mentioned only where they rest on a lore claim that Legends contradicts.
- Every item cites a Wookieepedia page and section. "Catalog §5d" etc. refers to the catalog's own section numbers. "P1a §C1" etc. points to the entry in this set.

**Scope limits (read first).**
1. **The lore file was not available.** The catalog says its source of truth is `SW_Force_Abilities_Forms_v3_complete.md` (about 140 abilities). That file was not seen. "Missing" below means missing from the catalog document only; a power may still exist in the lore file.
2. **Lightsaber forms (catalog §5k) were not checked.** They are outside the Force-powers files.
3. **The catalog has no numeric scale classes or feat gates.** It defers them to the "reserve spec", which was not provided. Item e therefore checks only the qualitative scale statements the catalog makes ("scale up to fleets", "scale = a star", "master anywhere they can see", and so on).
4. **The catalog's opening line links to an external chat artifact.** It was ignored.
5. **Severity labels used below:** **conflict** = the catalog states something a Legends page contradicts; **gap** = Legends has something the catalog omits; **note** = the catalog is defensible but rests on a hedged, disputed or thin source.

**Most important findings:**
1. **Midi-chlorian manipulation (d1).** The catalog writes "the Force itself created Anakin" as fact. Wookieepedia gives it as Plagueis's belief.
2. **Flow-walking (d2) and time-drifting (d3).** The catalog says the past cannot be changed and drops time-drifting. Wookieepedia says flow-walkers could alter the past, and that time-drifting is travel in time whose visitors can change events if seen.
3. **Battle meditation tagged Light (c1).** Legends has no side category for it and a whole "Dark side users" section (Sith battle meditation).
4. **Tutaminis vs Force Absorb (b1).** "Force absorb" redirects to Tutaminis on Wookieepedia; the catalog has two separate powers with different tiers.
5. **Purification (Crystal) (b2)** has only a Canon basis (kyber purification).
6. **Supernova "scale = a star" (e1)** is below the anchors: Naga Sadow made binary suns collide, and Aleema Keto's backfire ignited nine other stars.
7. **Lore-locks that Legends breaks (f).** Fold space (Luke, Leia, Abeloth), Theran Force-listening (Qui-Gon, Obi-Wan, the Solos), Phase (An'ya Kuro), Darksight ("other names by other Force users").
8. **Missing core Jedi Path powers (a1–a3):** Life Detection (*prima vitae*), Sense Force (*tactus otium*) and *altus sopor*.
